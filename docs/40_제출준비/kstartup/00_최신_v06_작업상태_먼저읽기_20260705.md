## 추천 제출 스토리라인

1. 온비드 URL 하나를 입력하면 공고·물건 연결과 주요 값을 먼저 확인한다.
2. AI가 원문에 이미 보이는 값을 반복하지 않고, 초보자가 놓치기 쉬운 준비 빈칸을 체크리스트 우선순위로 연결한다.
3. 담당기관에 물어볼 문장을 체크리스트 안에서 바로 확인한다.
4. 여러 공고는 최근 살펴본 공고와 관심 공고로 남겨 준비 상태를 이어서 본다.

- 자필서명 또는 날인은 사용자가 직접 처리한다.
- UI와 제출 문구에서 `PDF 리포트`, `Q&A`, `공고 해석 리포트`, 특정 AI 공급자명, `Local MVP`, `로컬 분석 API`가 보이면 최신본이 아니다.
- 본 서비스는 자동 입찰, 입찰 대행, 낙찰 가능성 예측, 법률·권리관계 판단, 투자수익률 판단을 제공하지 않는다.
- 표지 개인정보, 서명 또는 날인, 첨부자료는 최종 제출 전 사용자가 직접 확인한다.
