# 온비드 공공자산 공고 해석 리포트 Agent

## 1. 아이템의 소개

온비드는 국유재산, 압류재산, 공공기관 보유 자산의 매각·임대 공고를 통합 제공하는 공공 플랫폼이다. 한국자산관리공사는 2026년 6월 기준 주요사업 관련 공공데이터 119종을 개방하고 있으며, 온비드 공고목록, 공고상세, 물건정보, 입찰정보, 입찰결과, 용어사전은 본 서비스의 핵심 입력 데이터다.

공고와 물건정보는 공개되어 있지만, 실제 입찰 준비자는 공고문, 첨부문서, 물건정보, 입찰방식, 보증금, 제출서류, 낙찰 후 납부·계약 의무를 한 번에 이해해야 한다. 개인, 소상공인, 공공자산 활용 창업자는 공고를 찾은 뒤에도 제출서류, 기한, 비용, 현장확인 책임을 놓치기 쉽다.

`온비드 공공자산 공고 해석 리포트 Agent`는 온비드 공고와 한국자산관리공사 공공데이터를 기반으로 공공자산 공고를 사용자 준비 문서로 바꾸는 AI 서비스다. 사용자가 공고 URL, 공고번호, 물건번호, 관심 지역·재산유형을 입력하면 공고 요약, 입찰 일정, 제출서류, 비용 후보, 낙찰 후 의무, 사용자 확인 리스크, 용어 설명, 원문 근거가 포함된 PDF 리포트를 생성한다.

이 서비스는 온비드 공식 절차를 대신 수행하거나 결과를 약속하는 도구가 아니다. 공식 공고와 공공데이터를 사용자가 스스로 확인할 수 있도록 구조화하는 준비 보조 Agent다.

## 2. 사업성 및 성장가능성

초기 고객은 온비드 입찰 초보 개인, 소상공인·자영업자, 공공자산 활용 창업자, 창업지원기관·컨설턴트다. 이들은 공공기관 임대공간이나 매각물건을 사업기회로 검토하지만 공고 해석, 서류 준비, 비용 확인, 낙찰 후 의무 파악에 반복적인 시간을 쓴다.

KAMCO 공공데이터에는 온비드 월별 입찰참가자 현황이 포함되어 있으며, 2013년 1월부터 2025년 12월까지 156개월의 월별 유효 입찰참가자 수를 제공한다. 이는 온비드 공고 탐색과 입찰 준비가 반복적으로 발생하는 시장임을 보여주는 근거다. 본 서비스는 공고 단위 건별 리포트, 관심 조건 월간 모니터링, 전문가/기관용 패키지로 확장할 수 있다.

시장진입은 국유재산 임대·매각 공고 3건 샘플 리포트 생성, 소상공인·예비창업자·컨설턴트 각 1명 이상 사용성 검증, 웹 MVP 공개, 창업지원기관/컨설턴트 대상 B2B 검증 순서로 진행한다. 초기 가격 가설은 건별 리포트 3,000~9,900원, 월 구독 19,000~49,000원, 기관용 패키지 월 99,000원 이상이다. 무료 샘플은 공고 1건 요약과 리스크 3개까지만 제공하고, 전체 체크리스트·비용 후보·확인 질문·PDF 저장 기능에서 유료 전환을 검증한다.

## 3. AI 및 공공데이터 활용성

본 서비스는 한국자산관리공사 차세대 온비드 공고목록 조회서비스, 공고상세 조회서비스, 공고상세 입찰정보 조회서비스, 공고상세 물건정보 조회서비스, 입찰결과 조회서비스, 온비드 용어사전, 온비드 월별 입찰참가자 현황을 활용한다.

처리 구조는 Data Collector, Notice Parser, Checklist Agent, Risk Guard Agent, Glossary Agent, Report Agent로 나눈다. Data Collector는 공고번호, 물건번호, 기관, 일정, 재산유형, 입찰방식, 가격 후보를 수집한다. Notice Parser는 공고문과 첨부문서에서 일정, 서류, 보증금, 낙찰 후 의무, 유의사항을 추출한다. Checklist Agent는 사용자 유형별 제출서류와 준비 순서를 생성한다. Risk Guard Agent는 현장확인, 인허가, 비용, 낙찰 후 기한, 사용자 책임 문구를 표시한다. Glossary Agent는 온비드 용어사전의 `Terminology`, `Glossary` 컬럼을 활용해 쉬운 설명을 연결한다. Report Agent는 요약, 일정표, 서류 체크리스트, 비용 후보, 리스크, 다음 액션을 PDF로 생성한다.

API 응답 조회시각을 리포트에 표시하고, 공고 원문과 공공데이터 값이 다르면 원문 우선 확인 필요로 표시한다. 개인정보와 사용자의 입찰 희망가격은 기본 저장하지 않고, 리포트 생성 세션 내 처리 또는 사용자 로컬 저장을 우선한다.

## 4. 아이템의 실현 가능성

대표자는 기존 문서 Agent PoC에서 공고문 분석, 제출서류 체크리스트, HWPX/PDF 산출, 룰 기반 검증표, 샘플 리포트 작성 경험을 축적했다. 이번 아이템에서는 이 경험을 온비드 공고 해석 리포트로 전환한다.

1차 MVP는 4주 단위로 진행한다. 1주차에는 온비드 공고·물건·입찰정보 데이터 필드를 정리하고, 2주차에는 국유재산 임대·매각 공고 파서와 체크리스트를 구현한다. 3주차에는 리스크 카드, 용어 설명, Q&A를 구현하고, 4주차에는 PDF 리포트 MVP와 사용자 테스트를 진행한다. 5~8주차에는 공고 유형 확장과 관심 조건 모니터링을 검증한다.

주요 온비드 API는 공공데이터포털에서 무료 JSON/XML 제공 데이터로 확인된다. 운영 시 공공데이터포털 상세 기준을 기준으로 갱신 주기와 이용 조건을 확인한다. 인증키 발급이나 트래픽 이슈가 있으면 공공데이터포털 명세, 샘플 응답, 온비드 공개 공고 원문, CSV 캐시를 이용해 오프라인 MVP를 먼저 만들고, 운영키 준비 후 실제 API 응답을 연결한다.

## 5. 아이템의 창의성 및 시장 파급력

본 아이템의 창의성은 단순 요약이 아니라 공공데이터 API, 공고 원문, 첨부문서, 용어사전, 사용자 유형을 결합해 공공자산 공고를 실행 가능한 준비 문서로 바꾸는 흐름에 있다.

온비드 직접 검색은 공고 탐색은 가능하지만 서류·일정·위험 문구를 사용자가 직접 해석해야 한다. 범용 LLM 요약은 최신 공고와 공공데이터 구조를 안정적으로 반영하기 어렵고 근거 표시가 약할 수 있다. 본 서비스는 공공데이터와 원문 링크를 붙인 근거 기반 리포트로 차별화한다.

사회적 효과는 정보 접근성 개선, 서류 누락·기한 착오 감소, KAMCO 공공데이터 활용 확대, 공공자산 활용 창업 촉진, GovTech SaaS 확장이다.

## 6. 팀 구성

대표자 윤동원이 PM, 기획, AI Agent 설계, PoC 개발, 리포트 검증을 직접 수행한다. 필요 시 공매·부동산·행정서류 전문가 자문을 월 2회 이내, 총 50만원 이하 범위에서 확보하고, 리포트 시각화와 사용자 테스트는 단기 외부 보조를 활용한다.

## 7. 기타사항

제출 패키지에는 과거 공개 온비드 공고를 재현한 샘플 입력과 샘플 분석 리포트를 포함한다. 샘플은 현재 입찰 참여 판단자료가 아니라, 서비스가 공고를 어떻게 구조화하고 사용자 준비 리포트로 바꾸는지 보여주기 위한 작동 예시다.

기존 제품 관련 자료는 동일 아이템이 아니라 문서 기반 AI Agent 경험으로만 설명한다. 제출 부록에는 KAMCO·온비드 공공데이터 흐름, 샘플 입력, 샘플 분석 리포트, 서비스 화면형 증빙을 중심으로 포함한다.
