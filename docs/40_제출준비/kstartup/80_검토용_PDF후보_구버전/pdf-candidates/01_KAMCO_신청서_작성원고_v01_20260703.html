아이템명OnBid Public Asset Doc Agent
아이템 요약설명온비드 공공자산 공고와 한국자산관리공사 공공데이터를 AI로 구조화해, 입찰 초보자와 소규모 사업자가 일정, 조건, 제출서류, 비용 후보, 유의 리스크를 근거와 함께 이해하도록 돕는 공공자산 공고 해석 리포트 서비스

1. 아이템의 소개

1-1. 개발 배경

온비드는 국유재산, 압류재산, 공공기관 보유 자산의 매각·임대 공고를 통합 제공하는 공공 플랫폼이다. KAMCO 사전 설문 양식 기준으로도 한국자산관리공사는 2026년 6월 현재 주요사업 관련 공공데이터 119종을 개방하고 있으며, 인기 오픈API에는 온비드 부동산 물건목록, 물건상세, 공고목록, 공고상세, 입찰결과 조회서비스가 포함된다. 공고와 물건정보는 공개되어 있지만, 실제 입찰 준비자는 공고문, 첨부문서, 물건정보, 입찰방식, 보증금, 제출서류, 낙찰 후 납부·계약 의무를 한 번에 이해해야 한다.

특히 개인, 소상공인, 공공자산을 활용해 창업을 검토하는 예비 사업자는 다음 문제를 겪는다.

  • 공고명과 물건정보는 찾았지만, 입찰 전 반드시 준비할 서류와 기한을 놓치기 쉽다.
  • 입찰보증금, 부가가치세, 보험료, 물품대부료, 잔대금 납부기한처럼 실제 비용과 일정에 영향을 주는 조항을 공고문 곳곳에서 찾아야 한다.
  • 현장설명 생략, 영업수익 보장 없음, 유관기관 허가사항은 입찰자 책임 같은 문구의 실무 의미를 이해하기 어렵다.
  • 낙찰 후 7일 이내 신청, 선납, 보증보험증권 제출 같은 후속 의무를 사전에 체크하지 못하면 낙찰 무효나 보증금 귀속 위험이 생길 수 있다.

1-2. 아이템 내용

OnBid Public Asset Doc Agent는 온비드 공고와 한국자산관리공사 공공데이터를 기반으로 공공자산 공고를 사용자 준비 문서로 바꾸는 AI 서비스다.

사용자가 온비드 공고 URL, 공고번호, 물건번호, 관심 지역·재산유형을 입력하면 서비스는 다음 결과를 생성한다.

  1. 공고 핵심 요약
  2. 입찰 일정과 마감 알림 후보
  3. 제출서류 체크리스트
  4. 입찰보증금, 사용료, 부가세, 보험료 등 비용 후보
  5. 낙찰 후 의무와 기한
  6. 현장 확인, 인허가, 권리관계 등 사용자 확인 리스크
  7. 어려운 온비드·공매 용어의 쉬운 설명
  8. 원문 근거 링크와 공공데이터 출처가 포함된 PDF 리포트

본 서비스는 온비드 공식 절차를 대신 수행하거나 결과를 약속하는 도구가 아니다. 공식 공고와 공공데이터를 사용자가 스스로 확인할 수 있도록 구조화하는 준비 보조 Agent다.

1-3. 사용 시나리오

  1. 사용자는 온비드에서 관심 공고를 찾거나 서비스 검색 화면에서 지역·재산유형·입찰기간을 입력한다.
  2. 서비스는 온비드 공고목록과 물건정보를 조회해 후보 공고를 표준 스키마로 정리한다.
  3. 사용자가 공고를 선택하면 공고상세 입찰정보, 물건정보, 첨부 공고문, 온비드 용어사전을 함께 분석한다.
  4. AI Agent가 공고 요약, 일정, 제출서류, 비용 후보, 리스크를 생성하되 각 항목에 원문 근거를 붙인다.
  5. 사용자는 PDF 리포트와 Q&A를 보며 본인 상황에 맞는 확인 질문을 정리하고, 최종 입찰 여부는 원문과 담당기관 확인 후 결정한다.

2. 사업성 및 성장가능성

2-1. 목표 고객

고객군문제제공 가치
온비드 입찰 초보 개인공고문과 전자입찰 절차를 이해하기 어려움일정·서류·비용·리스크를 한 장 리포트로 확인
소상공인·자영업자공공기관 임대공간, 매각물건을 사업기회로 검토하나 준비 서류와 조건이 복잡함사업자 기준 준비물과 낙찰 후 의무를 체크리스트로 제공
공공자산 활용 창업자학교, 공공시설, 유휴공간 공고를 사업 아이디어와 연결하고 싶음지역·용도·면적·예정가격 기반 후보 탐색과 비교

2-2. 시장진입 전략

초기 시장은 온비드 공고 해석과 입찰 준비를 어려워하는 개인·소규모 사업자로 좁힌다. 1차 MVP는 국유재산 임대·매각 공고 중심으로 시작한다. 이후 차량, 동산, 압류재산, 입찰결과 비교, 지역별 통계 기반 후보 탐색으로 확장한다.

KAMCO 공공데이터 목록 자체가 온비드 물건·공고·입찰결과·용어사전으로 세분화되어 있다는 점은 반복 사용 가능성을 보여준다. 사용자는 공고 1건을 읽을 때마다 일정, 서류, 보증금, 낙찰 후 의무를 다시 확인해야 하므로, 공고 단위 리포트는 건별 사용과 관심 조건 모니터링 모두로 확장할 수 있다.

초기 획득 채널은 온비드 초보자 대상 검색 콘텐츠, 소상공인·창업자 커뮤니티, 공공자산 활용 창업 사례 콘텐츠, 창업지원기관·컨설턴트 대상 샘플 리포트 배포로 잡는다. 1차 검증은 소상공인/예비창업자/컨설턴트 각 1명 이상에게 샘플 리포트를 보여주고, 공고 이해도, 누락 방지 효과, 유료 리포트 사용 의향, 기관용 반복 사용 가능성을 확인한다.

2-4. 성장가능성

KAMCO와 온비드가 보유한 공공자산 데이터는 입찰공고, 물건정보, 입찰결과, 용어사전, 통계 데이터로 확장성이 높다. 본 아이템은 특정 공고 1건을 요약하는 데서 끝나지 않고, 공고 탐색, 후보 비교, 제출서류 준비, 낙찰 후 의무 체크, 유사 공고 학습으로 확장할 수 있다.

데일컴퍼니는 기존 문서 Agent PoC에서 공고문·양식·제출서류를 구조화하고 HWPX/PDF 문서로 산출한 경험이 있다. 이 경험을 공공자산 도메인으로 전환하면, 짧은 기간 안에 실제 사용자가 볼 수 있는 리포트 MVP를 만들 수 있다.

  • 공고 첨부문서의 법적 효력을 AI가 해석하지 않고, 담당기관·전문가 확인 필요 항목으로 분리한다.
  • 개인정보와 사용자의 입찰 희망가격은 기본 저장하지 않고, 리포트 생성 세션 내 처리 또는 사용자 로컬 저장을 우선한다.
  • 낙찰 가능성, 수익성, 권리관계, 법률 판단은 제공 범위에서 제외한다.

5-2. 창의성

본 아이템의 창의성은 AI로 공고를 예쁘게 요약하는 데 있지 않다. 공공데이터 API, 공고 원문, 첨부문서, 용어사전, 사용자 유형을 결합해 공공자산 공고를 실행 가능한 준비 문서로 바꾸는 흐름에 있다.

즉, 온비드가 제공하는 공고 데이터의 접근성을 높이고, 사용자가 입찰 전 준비해야 할 실제 행동을 구조화한다. 이는 KAMCO 공공데이터 활용을 일반 국민 서비스 개선과 창업 서비스 개발로 연결하는 방식이다.

5-3. 사회적 가치와 파급효과

효과설명
정보 접근성 개선공매·입찰 경험이 적은 사용자도 공고 핵심과 준비사항을 이해할 수 있다.
서류 누락·기한 착오 감소제출서류와 일정 체크리스트를 통해 준비 오류를 줄인다.

공공자산 활용 창업 촉진공공시설 임대, 국유재산 활용, 소규모 사업 기회 탐색을 돕는다.

7. 기타사항

7-1. 제출 전 샘플 산출물

현재 제출 패키지에는 실제 온비드 국유재산 임대 공고를 기반으로 만든 샘플 입력과 샘플 분석 리포트를 포함한다.

  • 샘플 입력: 온비드 국유재산 임대 공고 구조화 데이터
  • 샘플 출력: 공고 요약, 일정, 제출서류, 비용 후보, 리스크, 다음 액션, Q&A 리포트
  • 평가항목 매핑표: 사업성, 공공데이터 활용성, 실현 가능성, 창의성 대응표

7-2. 수상 이력

동일 아이템으로 기존 또는 타 기관 창업경진대회에서 입상한 이력은 없음으로 작성한다. 단, 최종 제출 전 사용자 확인이 필요하다. 기존 Bizketch 관련 제출 이력은 동일 아이템이 아니라 문서 기반 AI Agent 경험으로만 설명하고, 기존 사업명·공고명·수요기업명은 제출 본문 전면에 노출하지 않는다.

7-3. 제외 범위

  • 낙찰 가능성 보장
  • 투자수익률 예측 또는 보장
  • 법률·권리관계 판단 대체
  • 감정평가 대체

  • 온비드 공식 절차 대체

7-4. 최종 요약 문장

OnBid Public Asset Doc Agent는 KAMCO와 온비드가 개방한 공공데이터를 AI 문서 Agent로 연결해, 공공자산 공고를 검색 결과가 아니라 사용자가 바로 확인할 수 있는 일정·서류·비용·리스크 리포트로 바꾸는 GovTech 서비스다.
