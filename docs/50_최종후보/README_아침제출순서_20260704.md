## 사용자 직접 확인 항목

| 항목 | 확인 |
| --- | --- |
| 생년월일, 휴대전화, 이메일 | 실제 값으로 입력 |
| 창업일자, 사업장 주소 | 사업자등록증명 기준으로 입력 |
| 개인정보 동의서와 참가서약서 | 자필서명 또는 공식 양식이 허용하는 방식으로 서명 |
