# 서비스 입출력 및 사용자 가치 재정의

작성일: 2026-07-04

## 핵심 판단

기존 표현인 `공고 해석 리포트`는 내부 기술 역량은 보이지만, 사용자가 실제로 얻는 가치가 약하게 보인다. 제품의 중심을 `공공자산 공고 준비 보드`로 바꾸는 것이 더 명확하다.

사용자는 온비드 공고를 읽고 싶은 것이 아니라, 이 공고를 진행하려면 무엇을 언제까지 어디서 준비해야 하는지 알고 싶다. 따라서 산출물은 단순 요약 리스트가 아니라 실행 가능한 준비 보드여야 한다.

## 사용자 입력

| 상황 | 사용자가 입력하는 것 | 시스템이 자동 처리하는 것 |
| --- | --- | --- |
| 이미 관심 공고가 있음 | 온비드 공고 URL 또는 공고번호, 사용자 유형, 내 검토 목적 | URL 안의 공고번호·물건번호, 공고명, 기관, 재산유형, 처분방식, 일정, 보증금, 첨부문서 추출 |
| 아직 공고를 찾는 중 | 관심지역, 처분방식, 재산유형, 예산·면적·마감기간, 사용자 유형 | 조건에 맞는 공고 목록, 마감 임박 여부, 후보 비교 |
| 여러 공고를 비교 중 | 관심 공고 저장, 준비상태 변경 | 공고별 마감일, 누락 서류, 다음 액션 보드화 |

URL을 붙여 넣는 경우 공고번호와 물건번호는 사용자가 다시 입력하지 않는다. 사용자가 직접 입력해야 할 핵심값은 `내 목적`, `내 유형`, `관심조건`, `준비상태`다.

## 사용자 출력

| 출력 | 사용자 가치 |
| --- | --- |
| 적합성 판정 | 매각을 찾는 사용자가 임대 공고를 보고 있는 상황처럼 목적과 공고 유형이 어긋나는 것을 초기에 막는다. |
| 핵심 요약 | 공고명, 재산유형, 처분방식, 입찰방식, 보증금, 마감일, 낙찰 후 의무를 한 화면에서 파악한다. |
| 오늘 할 일 | 사용자가 지금 확인해야 할 항목을 3~5개로 줄여준다. |
| 서류 준비 링크 | 사업자등록증명, 본인서명사실확인서, 법인등기사항증명서, 전자보증서 등 준비처를 바로 열 수 있게 한다. |
| 마감 알림 후보 | 입찰마감, 전자보증서 신청, 원본서류 제출, 낙찰 후 계약 기한을 캘린더/알림 후보로 만든다. |
| 담당기관 확인 질문 | 법률·권리관계 판단을 대신하지 않고, 사용자가 담당기관에 물어볼 질문을 원문 근거와 함께 정리한다. |
| 관심 공고 보드 | 여러 공고의 마감일, 준비상태, 누락 항목을 비교해 반복 사용 가치를 만든다. |
| 검토 메모/공유 | 본인 검토, 동업자 공유, 담당기관 문의에 쓸 수 있는 핵심 메모를 복사하거나 공유한다. |

## MVP 화면 기준

| 화면 | 역할 |
| --- | --- |
| 공고 가져오기 | URL/공고번호, 사용자 유형, 내 검토 목적을 입력하고 공고 유형과 목적의 일치 여부를 확인한다. |
| 준비 보드 | 핵심 요약, 체크 가능한 할 일, 공식 준비처 링크, 담당기관 질문, 원문 근거, 마감/비용 후보를 한 화면에서 보여준다. |
| 관심 공고 | 여러 공고의 준비상태와 다음 확인 항목을 비교한다. |
| 검토 메모 | 담당기관 문의나 공동 검토에 쓸 핵심 내용을 복사한다. |

## 신청서용 한 문장

`OnBid Public Asset Doc Agent`는 온비드 공고 URL 또는 관심조건을 입력하면 공고 유형, 일정, 비용, 제출서류, 공식 준비처 링크, 담당기관 확인 질문을 한 화면의 실행 체크리스트로 바꾸어 주는 공공자산 입찰 준비 보드 서비스다.

## 제외 범위

- 자동 입찰
- 입찰 대행
- 낙찰 가능성 또는 수익성 예측
- 법률·권리관계 판단 대체
- 현장조사 대체
- 온비드 공식 절차 대체
