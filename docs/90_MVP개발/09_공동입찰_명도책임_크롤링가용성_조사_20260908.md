## 2. 표본 실측 — 공동입찰

### 2-1. 어디에 있는가 `[관측]`

- 절: `split_sections()` 기준 **`입찰방법`** 절. `공고문`·`제출서류` 절이 아니다.
- DOM 구조는 라벨/값이 좌우로 갈린 항목 박스다.

```html
<div class="tit_area01">
  <span class="txt_01">공동입찰</span>
  <div class="tooltip_wrap01"> … 온비드 UI 도움말 … </div>
</div>
…
<div class="right_box">
  <div class="ico_box01"><span class="ico"></span><span class="txt_01">가능</span></div>
</div>
```

- 라벨과 값 **둘 다 `txt_01`** 이다. 값 클래스가 `txt01` 인 다른 절과 구조가 다르다.
- 라벨과 값 사이에 툴팁 블록(수백 자)이 끼어 있다.

### 2-2. 검출률과 어휘 `[관측]`

`입찰방법` 절만 대상으로 셌다(계측 스크립트 `/tmp/joint_measure.py`).

| 항목 | 실측 |
| --- | --- |
| 공동입찰 값 검출 | **23/23** |
| 어휘 | `가능` · `불가능` — 이 둘뿐 |
| 값 분포 | 가능 12/23 · 불가능 11/23 |
| 대리입찰 값 검출 | 23/23 (가능 12 · 불가능 11) |

- 「해당없음」·「미기재」·빈 값은 표본에 **없었다**.
- 공동입찰과 대리입찰이 **서로 다른 표본이 2건** 있다 — 축을 하나로 묶으면 안 된다.
  - `pbanc_17`: 공동=가능 · 대리=불가능
  - `pbanc_22`: 공동=불가능 · 대리=가능

### 2-3. 기존 코드가 이 값을 못 읽는 이유 `[관측]`

- `label_value()` (`src/server.py:137`) 를 `입찰방법` 절 + 라벨 `공동입찰` 로 돌리면
  **23/23 모두 빈 문자열**을 반환한다.
- 원인은 값 span 의 클래스다. `label_value` 는 값을 `txt01` 로 찾고 `txt_01` 은 「다음 라벨」로 본다.
  값 span 이 `txt_01` 이라 `next_label` 이 먼저 걸려 `continue` 로 빠진다. `[추론]`
- 즉 **기존 헬퍼를 그대로 쓸 수 없고 전용 추출기가 필요하다.**
