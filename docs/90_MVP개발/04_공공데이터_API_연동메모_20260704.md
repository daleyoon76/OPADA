작성일: 2026-07-04

## 현재 구현

- `app/server.py`는 온비드 URL을 먼저 실제 공개 페이지로 fetch한다.
- HTML hidden input과 화면 텍스트에서 `cltrMngNo`, `pbctCdtnNo`, `pbancMngNo`를 추출한다.
- 공공데이터포털 인증키가 있으면 아래 API를 호출해 물건/입찰 정보를 보강한다.
- 인증키가 없거나 API가 실패해도 기존 온비드 HTML 분석 결과는 유지하고, 화면에 API 상태를 표시한다.
- API가 200/`NODATA_ERROR`를 반환하면 공공데이터 조회값 없음으로 분류하고, 사용자 화면은 온비드 원문 HTML 분석값으로 정상 생성한다.
- 2026-07-04 기준 공공데이터포털 로그인 후 온비드 관련 개발계정 활용신청 6건을 승인받았다.

## 검증 상태

- 인증키 미설정: `analysisMeta.publicData.status=missing_key` 확인.
- 잘못된 인증키: 실제 API가 401을 반환하고 `status=failed`로 분류되는 것 확인.
- 실제 인증키: 사용자 short URL 기준 `real_estate_detail`, `item_bid_detail`은 200/`NODATA_ERROR`를 반환했다. 서버는 이를 `status=no_data`로 분류하고 화면에는 `API 보조 없음` 배지를 표시한다.
- 실제 인증키: 승인 직후 일부 상세 API가 403을 반환하는 경우 서버는 `status=pending`으로 분류하고 `API 권한 대기` 배지를 표시한다.
- 로컬 MVP 화면: 인증키가 있을 때도 API 조회값이 없거나 권한 반영 대기 상태이면 HTML 분석 결과는 계속 유지한다. 실제 사용자 산출물은 온비드 원문 기준 준비 보드로 생성된다.

## 로그인 필요 지점

공공데이터포털에서 각 온비드 API에 대해 `활용신청`을 누르는 시점에 로그인이 필요하다. 인증키는 파일에 저장하지 않고 위 환경변수에만 넣어 서버를 재시작한다.
