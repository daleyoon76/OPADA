# OnBid Public Asset Doc Agent Spec

작성시각: 2026-07-04 00:18 KST

## 목표

온비드 공공자산 공고를 일반 사용자도 이해 가능한 준비 리포트로 변환한다.

## 입력

| 입력 | 설명 |
| --- | --- |
| 공고 URL 또는 공고관리번호 | 온비드 공고 식별자 |
| 물건관리번호 | 물건 상세 조회용 |
| 사용자 유형 | 개인, 개인사업자, 법인, 예비 창업자 |
| 관심 목적 | 임대, 매각, 사업공간 탐색, 차량/동산 매입 등 |

## 데이터 소스

| 데이터 | 우선순위 |
| --- | --- |
| 온비드 공고상세 원문 | 1 |
| 공고상세 입찰정보 API | 1 |
| 물건목록/상세 API | 1 |
| 온비드 용어사전 | 2 |
| 입찰결과 API | 2 |
| 지역별/용도별 통계 | 3 |

## 처리 흐름

1. 공고 식별자 입력
2. 공고·물건·입찰정보 조회
3. 원문과 API 필드 정합성 체크
4. 공고 섹션 분류
5. 일정·서류·비용·낙찰 후 의무 추출
6. 용어 설명 연결
7. 리스크 카드 생성
8. 사용자 확인 질문 생성
9. PDF 리포트 및 Q&A 생성

## 출력

| 출력 | 설명 |
| --- | --- |
| 공고 요약 | 한 줄 요약과 핵심 조건 |
| 일정표 | 입찰, 서류, 개찰, 낙찰 후 의무 |
| 제출서류 체크리스트 | 사용자 유형별 준비 서류 |
| 비용 후보 | 보증금, 사용료, 부가세, 보험료, 잔대금 등 |
| 리스크 카드 | 현장확인, 인허가, 권리관계, 기한 미준수 |
| Q&A | 원문 근거 기반 답변 |
| PDF 리포트 | 사용자 저장·공유용 |

## 제외 범위

- 입찰 대행
- 자동 입찰
- 낙찰 가능성 예측
- 투자수익률 예측
- 법률·권리관계 판단
- 현장조사 대체
- 감정평가 대체

## MVP 기준

| 항목 | 기준 |
| --- | --- |
| 공고 유형 | 국유재산 임대·매각 우선 |
| 샘플 수 | 3건 |
| 리포트 생성 시간 | 1건당 2분 이내 목표 |
| 검증 | 수작업 체크리스트와 항목 일치율 비교 |
| 사용자 테스트 | 소상공인/예비 창업자 3명 이상 피드백 목표 |
