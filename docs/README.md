# KAMCO Startup TechBlaze - OnBid Public Asset Doc Agent

작성시각: 2026-07-03 23:45 KST

## 제출 방향

KAMCO Startup TechBlaze 모집부문 1, `AI 및 공공데이터 활용 제품 및 서비스 개발`로 지원한다.

제안명은 `온비드 공공자산 공고 해석 리포트 Agent(OnBid Public Asset Doc Agent)`다. 기존 제품을 그대로 제출하지 않고, 공고문 해석, 문서 구조화, 근거 기반 리포트, 체크리스트 생성 경험을 한국자산관리공사·온비드 공공데이터에 맞춘 공공자산 공고 해석 서비스로 변형한다.

## 현재 판정

`Modify-Go` 상태다. 사업 아이템과 제출 원고는 준비 가능하지만, 최종 제출 전 사용자 확인과 자필서명, 신분증/사업자등록증 첨부 승인이 필요하다.

## 핵심 품질 기준

- 첫 70%는 KAMCO·온비드 전용 문제, 데이터, 샘플 산출물로 구성한다.
- 기존 제품 화면과 HWPX/PDF 경험은 뒤쪽 부록으로만 둔다.
- 투자수익, 낙찰 가능성, 법률·권리관계 판단, 입찰 대행을 보장하거나 대체한다고 표현하지 않는다.
- 공공데이터 출처와 활용 방법을 명시한다.
- 1인기업 리스크는 범위 축소, 주차별 산출물, 외부 자문, 사용자 검수 흐름으로 방어한다.
