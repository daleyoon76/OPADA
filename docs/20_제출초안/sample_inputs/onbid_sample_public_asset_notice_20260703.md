## 샘플 사용 목적

이 입력은 현재 입찰 참여용 판단자료가 아니라, `OnBid Public Asset Doc Agent`가 온비드 공고를 어떻게 구조화하고 사용자 준비 리포트로 바꾸는지 보여주기 위한 과거 공개 공고 재현 샘플이다. 실제 서비스에서는 원문 링크, 공공데이터 API 응답, 첨부문서 원문, 사용자가 선택한 입찰자 유형을 함께 사용한다.
