# 샘플 출력 v01 - 온비드 공공자산 공고 분석 리포트

서비스명: OnBid Public Asset Doc Agent  
샘플 공고: 국유재산(국립군산대학교 제2학생회관 복사 및 인쇄점) 유상사용 수익허가자 선정  
샘플 성격: 과거 공개 공고 재현 샘플. 현재 입찰 참여 판단자료가 아님

## 1. 한 줄 요약

군산대학교 제2학생회관 내 110.81㎡ 공간을 복사 및 인쇄점 용도로 3년간 사용하는 국유재산 임대 공고이며, 온비드 전자입찰로 진행되고 입찰 전 서류 제출과 낙찰 후 7일 이내 사용수익허가 신청·납부 의무가 핵심이다.

## 7. 다음 액션

1. 온비드 회원가입 및 인증서 등록 상태를 확인한다.
2. 입찰참가자격 서류 발급 가능일과 직접 제출 가능 시간을 확인한다.
3. 현장을 방문하거나 공고 담당자에게 운영 제한, 기존 시설, 전기·네트워크·장비 반입 조건을 확인한다.
4. 연간 사용료, 부가세, 보험료, 물품대부료, 보증보험 비용을 합산한 1년 비용표를 만든다.
5. 낙찰 후 7일 이내 사용수익허가 신청과 선납이 가능한 자금 계획을 확인한다.

## 9. 서비스 주의문

본 리포트는 공고 원문과 공공데이터를 사용자가 이해하기 쉬운 체크리스트로 정리한 참고자료다. 입찰 참가 여부, 법률·권리관계, 사업성, 낙찰가, 수익성 판단은 사용자가 원문 공고, 첨부문서, 담당기관, 전문가 확인을 통해 최종 결정해야 한다.
