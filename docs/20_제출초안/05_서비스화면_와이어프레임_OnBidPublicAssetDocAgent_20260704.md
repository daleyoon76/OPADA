# 서비스 화면형 증빙 - OnBid Public Asset Doc Agent

## 화면 1. 공고 선택

```text
┌──────────────────────────────────────────────────────────────┐
│ OnBid Public Asset Doc Agent                                  │
├──────────────────────────────────────────────────────────────┤
│ 공고 URL 또는 공고번호                                        │
│ https://www.onbid.co.kr/...                                   │
│                                                              │
│ 관심 유형                                                     │
│ [국유재산 임대] [국유재산 매각] [압류재산] [공공기관 자산]      │
│                                                              │
│ 사용자 유형                                                   │
│ [개인] [개인사업자] [법인] [창업 준비자]                       │
│                                                              │
│ 실행                                                         │
│ [공공데이터 조회] [공고문 첨부 확인] [리포트 생성]             │
└──────────────────────────────────────────────────────────────┘
```

## 화면 2. 공공데이터 구조화

| 수집 데이터 | 표시 필드 | MVP 표시 예시 |
| --- | --- | --- |
| 공고목록 조회서비스 | 공고명, 공고기관, 공고일, 회차 | 조회 후 표시 |
| 공고상세 조회서비스 | 공고문, 첨부파일, 재산유형, 처분방식 | 조회 후 표시 |
| 공고상세 물건정보 조회서비스 | 물건명, 소재지, 용도, 유찰횟수, 입찰기간 | 조회 후 표시 |
| 공고상세 입찰정보 조회서비스 | 공동입찰, 보증금, 잔대금 납부, 참가신청 | 조회 후 표시 |
| 온비드 용어사전 | 용어, 설명 | 매칭 후 표시 |

## 화면 3. 리포트 미리보기

```text
┌───────────────────────┬──────────────────────────────────────┐
│ 공고 한 줄 요약        │ 국유재산 임대, 전자입찰, 서류 별도 제출 │
├───────────────────────┼──────────────────────────────────────┤
│ 마감 경고              │ 입찰·보증금·서류 제출 마감 D-3          │
├───────────────────────┼──────────────────────────────────────┤
│ 제출서류               │ 사업자등록증명, 등본/등기부, 인감증명 등 │
├───────────────────────┼──────────────────────────────────────┤
│ 비용 후보              │ 사용료, 부가세, 보험료, 보증보험        │
├───────────────────────┼──────────────────────────────────────┤
│ 확인 리스크            │ 현장확인, 인허가, 납부기한, 원문 우선    │
└───────────────────────┴──────────────────────────────────────┘
```

## 사용자 가치

| 기존 방식 | Agent 적용 후 |
| --- | --- |
| 공고문과 첨부문서를 직접 읽으며 제출서류를 찾는다 | 사용자 유형별 제출서류와 마감이 한 화면에 정리된다 |
| 보증금, 잔대금, 부가비용을 따로 계산한다 | 비용 후보와 확인 필요 항목이 구분된다 |
| 어려운 입찰 용어를 별도로 검색한다 | 온비드 용어사전 기반 설명이 함께 표시된다 |
| 놓친 조건은 담당기관 문의 전까지 발견하기 어렵다 | 담당기관에 물어볼 질문이 리스크 카드로 생성된다 |

## 구현 범위

1차 MVP는 공고 해석, 제출서류 체크리스트, 비용 후보, 리스크 질문, PDF 리포트 생성에 집중한다. 전자입찰 절차 수행, 입찰가 제안, 수익성 판단, 법률·권리관계 판단은 서비스 범위에서 제외한다.
