# 평가 대응 요약 - OnBid Public Asset Doc Agent

## KAMCO 모집부문 적합성

본 아이템은 한국자산관리공사가 개방한 온비드 공공데이터를 활용해 국민이 공공자산 공고를 더 쉽게 이해하고 준비하도록 돕는 AI 서비스다. 모집부문 ①의 `AI 및 공공데이터 활용 제품 및 서비스 개발`에 맞춰 공공데이터 API, 공고 원문, 첨부문서, 용어사전을 하나의 사용자 리포트로 연결한다.

## 평가 기준별 설계

| 평가항목 | 배점 | 제안 내용 | 제출 산출물 |
| --- | --- | --- | --- |
| 사업성 및 성장가능성 | 30 | 온비드 입찰 초보 개인, 소상공인, 공공자산 활용 창업자가 반복적으로 겪는 공고 해석·서류 준비·마감 확인 문제를 해결 | 신청서 본문, 샘플 리포트 |
| AI 및 공공데이터 활용성 | 30 | KAMCO/온비드 공고목록, 공고상세, 물건정보, 입찰정보, 입찰결과, 용어사전을 결합해 근거 기반 리포트를 생성 | 공공데이터 활용 구조도, API 필드 매핑 |
| 실현 가능성 | 20 | 4주 MVP 범위를 공고 해석, 체크리스트, 리스크 질문, PDF 리포트로 좁히고 기존 문서 Agent PoC 경험을 활용 | 서비스 화면형 증빙, 추진계획 |
| 창의성 및 시장파급력 | 20 | 단순 공고 검색이나 일반 요약이 아니라 공공자산 공고를 실행 가능한 준비 문서로 전환 | 샘플 입력·출력, 사용자 가치 표 |

## 서비스 범위

| 제공 기능 | 경계 |
| --- | --- |
| 공고 요약, 일정표, 제출서류 체크리스트 | 사용자의 최종 의사결정을 대신하지 않음 |
| 비용 후보와 확인 필요 항목 정리 | 입찰가나 수익성을 제안하지 않음 |
| 현장확인, 인허가, 납부기한 등 리스크 질문 생성 | 법률·권리관계 판단을 대신하지 않음 |
| 온비드 용어사전 기반 쉬운 설명 | 공고 원문과 담당기관 확인을 우선 표시 |

## 기대효과

| 대상 | 기대효과 |
| --- | --- |
| 일반 국민·소상공인 | 공고 이해 시간 단축, 서류 누락과 마감 착오 감소 |
| KAMCO/온비드 | 공공데이터 활용 사례 확대, 온비드 정보 접근성 향상 |
| 창업 생태계 | 공공자산을 활용한 창업 기회 탐색과 GovTech 서비스 확산 |
