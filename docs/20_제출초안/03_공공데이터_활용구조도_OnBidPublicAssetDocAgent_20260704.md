# 공공데이터 활용 구조도 - OnBid Public Asset Doc Agent

## 한 장 구조

```text
KAMCO/OnBid 공공데이터
  ├─ 공고목록 조회서비스
  ├─ 공고상세 입찰정보 조회서비스
  ├─ 물건목록·상세 조회서비스
  ├─ 입찰결과 조회서비스
  └─ 온비드 용어사전
        ↓
Data Collector
  - 공고번호, 물건번호, 기관, 일정, 재산유형, 입찰방식, 가격 후보 수집
        ↓
Notice Parser
  - 공고문/첨부문서에서 일정, 서류, 보증금, 낙찰 후 의무, 유의사항 추출
        ↓
Checklist Agent
  - 사용자 유형별 제출서류, 마감, 준비 순서 생성
        ↓
Risk Guard Agent
  - 현장확인, 인허가, 비용, 낙찰 후 기한, 사용자 책임 문구 표시
        ↓
Glossary Agent
  - 온비드 용어사전 기반 쉬운 설명 연결
        ↓
Report Agent
  - 요약, 일정표, 서류 체크리스트, 비용 후보, 리스크, 다음 액션 PDF 생성
```

## 데이터-기능 연결표

| 공공데이터 | 입력 필드 예시 | Agent 처리 | 출력 |
| --- | --- | --- | --- |
| 공고목록 조회서비스 | 공고번호, 공고명, 기관, 공고일, 입찰기간 | 조건별 공고 후보 수집 | 관심 공고 목록, 마감 임박 표시 |
| 공고상세 입찰정보 조회서비스 | 입찰방식, 입찰구분, 보증금, 잔대금 납부, 입찰제한 | 입찰 조건과 일정 추출 | 핵심 조건, 일정표, 준비 체크 |
| 물건목록·상세 조회서비스 | 재산유형, 물건유형, 소재지, 면적, 예정가격, 최저입찰가 | 물건 정보 표준화 | 물건 요약, 비용 후보, 비교표 |
| 입찰결과 조회서비스 | 회차, 낙찰 여부, 낙찰가, 유찰 여부 | 유사 공고 참고 정보 생성 | 반복 공고 탐색 힌트 |
| 온비드 용어사전 | 용어, 정의, 분야 | 쉬운 설명 연결 | 용어 설명 박스, Q&A 근거 |

## 샘플 출력 필드

| 리포트 항목 | 사용 데이터 | 사용자 가치 |
| --- | --- | --- |
| 한 줄 요약 | 공고명, 기관, 재산유형, 사용 목적 | 공고 성격 즉시 파악 |
| 핵심 조건 | 입찰방식, 사용기간, 예정가격, 소재지, 면적 | 관심 여부 판단 |
| 일정표 | 입찰서 제출, 보증금 납부, 서류 제출, 개찰, 낙찰 후 신청 | 마감 누락 방지 |
| 제출서류 체크리스트 | 공고문 서류 조항, 사용자 유형 | 준비물 누락 방지 |
| 비용 후보 | 예정가격, 보증금, 부가세, 보험료, 잔대금 | 실제 필요 자금 확인 |
| 리스크 카드 | 현장설명 생략, 수익 미보장, 인허가 책임, 낙찰 후 의무 | 담당기관에 물어볼 질문 도출 |
| 용어 설명 | 온비드 용어사전 | 공매·입찰 용어 이해 |

## API 지연 시 fallback

| 상황 | 대체 방식 |
| --- | --- |
| 인증키 발급 지연 | 공공데이터포털 명세와 샘플 응답으로 스키마 우선 구현 |
| 트래픽 제한 | 조회 결과 캐시와 조회시각 표시 |
| 첨부문서 텍스트 추출 실패 | 공고 본문/API 필드 우선 리포트 생성, 첨부문서는 확인 필요로 표시 |
| 원문과 API 값 불일치 | 원문 우선 확인 필요 표시 및 담당기관 확인 질문 생성 |
