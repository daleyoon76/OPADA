# ONBID_API_SERVICE_KEY 발급 안내

- 작성: 2026-09-02
- 대상: `src/server.py`의 `PUBLIC_DATA_ENDPOINTS` 6종
- 성격: **보조 경로**입니다. 키가 없어도 온비드 공개 원문 분석은 그대로 동작합니다.

## 발급 절차

1. 공공데이터포털에 회원가입·로그인합니다 — https://www.data.go.kr/
2. 아래 6종을 각각 열어 `활용신청`을 누릅니다.
3. 신청 목적을 적고 제출합니다. 오픈API는 대부분 자동 승인됩니다.
4. `마이페이지 > 인증키 발급현황`에서 일반 인증키를 확인합니다 — https://www.data.go.kr/iim/api/selectAPIAcountView.do
5. 발급받은 키를 환경변수로 넣고 서버를 다시 띄웁니다.
   ```
   export ONBID_API_SERVICE_KEY='<발급받은 키>'
   python3 src/server.py
   ```

- 발급 후 실제 값은 `마이페이지 > 오픈API 활용현황(승인) > 오픈API 선택 > 활용신청 상세기능정보`에서 확인합니다.

## 키를 넣으면 달라지는 것

- 화면 하단 출처 영역의 문구가 `보조 데이터: ...`에서 연결 상태 문구로 바뀝니다.
- `tests/public-data-status.spec.js`의 API 상태 단언이 의미를 갖게 됩니다. 다만 그 단언은 `#report-hero`를 보는데 문구는 `#source-notes`로 옮겨졌으므로, 키를 넣어도 셀렉터 수정이 함께 필요합니다.
