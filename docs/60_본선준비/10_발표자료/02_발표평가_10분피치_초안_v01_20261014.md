# 발표평가 10분 피치 초안 (v01)

- 작성: 2026-10-14
- 기준 문서: `01_발표평가_5분피치_v06_20260902.md`(5분 포지션, 보존). 이 문서는 그 뒤에 추가된 **에이전틱 준비 가이드**(마법사 입력 + 순차 준비 보드 + AI 질문창) 작업을 반영해 10분 분량으로 새로 짠 안이다.
- 배정 시간: 발표 10분 + 질의응답 10분(2026-10-22 14:20~14:40). 절별 시간은 600초 기준 배분, 낭독 시간 미실측.
- 슬라이드로 옮길 때 참고: 이 조직의 자료 작성 규칙상 본문은 완결된 문장이 아니라 **명사형**으로 끝맺고, 나열은 불릿으로 쪼갠다.

## 0. 한 문장 소개 (20초)

- 온비드 공매·입찰 공고 주소 하나로 시작하는 **AI 준비 가이드**
- 처음 하는 사람도 끝까지 혼자 따라갈 수 있게, 단계별 안내와 서류 체크

## 1. 문제 (50초)

- 온비드 공고는 이미 공개 상태, 접근의 문제 아님
- 진짜 문제는 **준비**
  - 공고문·첨부문서·물건정보·입찰정보·보증금·제출서류, 전부 따로 확인
  - 일정 착오, 서류 누락, 비용 오해 발생
- 더 큰 문제는 **공고가 말하지 않는 항목**
  - 무엇을 모르는지조차 모르는 상태로 마감

## 2. 해결 — 에이전틱 준비 가이드 (150초)

- 핵심 전환: 요약 도구에서 **끝까지 같이 가는 가이드**로
- 입력 단계(마법사형 3단계)
  1. 내 유형·검토 목적 선택(초보/경험자, 임대/매각 등)
  2. 온비드 공고 URL 입력
  3. 분석 결과 확인(핵심 정보·확인 사항·온비드 연결, 세 묶음으로 정리)
- 준비 보드(순차 3단계, 앞 단계를 끝내야 다음이 열림)
  1. **공고 확인** — 입찰기간 만료·목적 불일치를 감지해 경고, "처음으로" 재시작 분기
  2. **서류 준비** — 공동입찰·대리입찰 여부를 질문으로 받아 서류 리스트를 자동 조건화, "내 보관함" 저장
  3. **입찰 참여** — 입찰기간·장소·최저입찰가격 등 참여 전 챙길 정보 리스트, **AI 질문창**
- AI 질문창
  - 사용자가 보고 있는 공고 맥락(유형·일정·가격·앞 단계 답)을 함께 넘겨 질문
  - 안전 경계 그대로 유지: 낙찰 가능성·적정가·법적 판단에는 답하지 않고 원문·담당기관 확인 안내

## 3. 실제 동작 — 직접 확인한 결과 (100초)

- 2026-10-12~10-14, 실제 온비드 공고로 전체 흐름 1회 완주 확인(실제 브라우저 테스트)
- 확인된 동작
  - 공동입찰·대리입찰 질문에 "예" 응답 시 서류 그룹 1종 → 5종으로 실제 확장
  - AI 질문창에 "최저입찰가격은 얼마인가요?" 입력 → 실제 모델 응답 수신
  - "낙찰 가능성이 높을까요?" 같은 판단 요구 질문 → 단정 없이 담당기관 확인 안내로 응답(안전 경계 실동작 확인)
  - "처음으로" 재시작 후 재진행까지 상태 꼬임 없음
- 단위 테스트 275건, 금지 문구 검사 20건, 전체 통과(변경 전후 동일)

## 4. 왜 공공데이터·원문 대조인가 (40초)

- 온비드 공개 원문이 기본 경로, 공공데이터포털 온비드 API가 보조 경로
- 단순 AI 요약이 아니라 **원문과 공공데이터 필드를 함께 대조**하는 것이 차별점
- 2026-09-02 한국자산관리공사 확인: 조회 데이터를 가공해 자사 화면에 보여주는 방식에 별도 제약 없음

## 5. 실현 가능성과 범위 (50초)

- 현재 범위: 온비드 공개 페이지 분석(임대/대부, 매각/공매 양쪽 처리)
- 1차 범위는 부동산 공고로 한정
- 제외한 것(신청서 단계부터 유지한 경계, 안전 경계와 동일선상)
  - 전자입찰 절차 대행
  - 법률 판단, 권리관계 판단, 수익성 판단
- 이번 분기 범위 밖으로 명시한 것(다음 마일스톤 후보)
  - 물건 검색·발굴(현재는 링크 입력부터 시작)
  - 보관함 저장 데이터의 재방문 복원(저장은 되나 불러오기는 아직 미구현)

## 6. 사업화 (50초)

- 초기 이용자: 온비드 처음 쓰는 일반 이용자, 소상공인, 공공자산 활용 창업자
- 1단계 실증 → 건별 과금 + 월 구독으로 확장
- 확장 후보: 관심 조건 모니터링, 창업지원기관·컨설턴트용 묶음

## 7. 마무리 — 안전 경계 선언 (40초)

- 이 서비스는 온비드 공식 절차를 대신 수행하지 않음
- 원문 그대로 유지(수정하지 않는다):
  > 본 서비스는 입찰 여부, 법률 판단, 투자수익률, 낙찰 가능성을 제공하지 않으며, 온비드 원문과 담당기관 확인을 우선하는 준비 보조 도구입니다.
- 공공데이터와 원문 근거로, 이용자가 **스스로** 준비하도록 돕는 도구
