# OPADA 리포트 1건당 원가 실측 — LLM API 변동비 중심

- 작성: 2026-10-16
- 대상 기능: `/api/analyze`(공고 URL 1건 → "분석 결과" 생성), 핵심 함수 `build_notice()`(`Hometest_op-agentic/src/server.py:2211`)
- 작성 배경: v04 슬라이드(`08_발표슬라이드_v04_20261015/`)가 건별 가격을 9,900원 → 4,900원으로 내릴 때 인용한 "원가 700~1,000원"은 **OPADA의 원가가 아니라 등기부등본 발급 비용**이었다. OPADA 자체의 건당 원가는 이번이 첫 실측이다.
- 조사 범위: **건당 변동비, 그중에서도 LLM API 비용 중심**이다. 서버 호스팅비는 월정액이라 건당으로 나누기 어려워 이번 조사에서 제외한다.
- 참고 문서: 18번 문서(`18_LLM질문답변_원가분석_요금제제안_20260921.md`)는 `/api/ask`(AI 코치 질문-답변) 기능의 원가를 다뤘다. **이번 문서는 그 기능과 별개인 리포트 생성(`/api/analyze`) 기능**을 다룬다.
- 이 문서는 분석·실측까지다. 슬라이드(v04 디렉터리)는 건드리지 않았다.

## 1. 리포트 생성 흐름의 LLM 호출 구조 [관측]

`build_notice(raw_url)`은 온비드 원문을 가져와 공고 필드를 추출하고, 마지막에 `build_ai_coach(notice, required_docs)`를 호출한다(`server.py:2468`). 이 한 자리가 리포트 생성 전체에서 **유일하게 LLM을 호출하는 지점**이다.

```
build_ai_coach()
  └─ vertex_ai_coach() 시도 (Vertex AI generateContent)
       성공하면 그대로 반환, 실패하면 ↓
  └─ gemini_ai_coach() 시도 (Gemini Developer API generateContent)
       실패하면 ↓
  └─ local_ai_coach() — 규칙 기반, LLM 호출 없음
```

- 정상 상황(Vertex 성공)에서는 **LLM 호출이 1회**다.
- Vertex가 실패하면 Gemini API로 1회 더 폴백해 **최대 2회**까지 늘어날 수 있다.
- 🔴 **흥미로운 특이점 [관측]**: `vertex_ai_coach()`·`gemini_ai_coach()` 둘 다, LLM 호출이 성공해도 **그 응답 내용을 실제로 쓰지 않는다**(`server.py:1669-1674`, `1751-1756`). LLM 응답은 JSON 파싱 성공 여부(`parsed`가 있는지)만 확인하는 데 쓰이고, 사용자에게 보여지는 "AI 코치" 텍스트는 `local_ai_coach()`의 **규칙 기반 결과**를 그대로 가져다 쓴다. 즉 이 LLM 호출은 "연결 확인용"에 가깝고, 실제 문구 생성 역할은 하지 않는다. 다만 과금은 요청·응답 토큰 수만큼 그대로 발생한다 — 응답을 버린다고 비용이 줄지는 않는다.

## 2. 프롬프트 구조와 길이 [관측]

`vertex_ai_coach()`/`gemini_ai_coach()`가 만드는 프롬프트는 고정 `instruction` 문장(약 300자) + `notice` 필드 10개(제목·자산유형·처분방식·입찰방법·입찰기간·마감·가격·감정가·기관·담당부서·필요서류 최대 4개) + 고정 `schema` 설명으로 구성된다. 출력은 `generationConfig.maxOutputTokens: 1000`으로 상한이 걸려 있다(`server.py:1651`, `1731`).

## 3. 공공데이터 API·온비드 크롤링 비용 [관측 + 추론]

- `fetch_onbid()`(`server.py:869`)는 `www.onbid.co.kr` 공개 페이지를 일반 HTTP GET으로 가져온다. 인증·과금 없는 공개 웹페이지 요청이다. **[관측]**
- `fetch_public_data_bundle()`(`server.py:1158`)이 호출하는 엔드포인트는 전부 `https://apis.data.go.kr/B010003/...`(`server.py:29-34`), 즉 **공공데이터포털(data.go.kr) Open API**다. 06번 문서(`06_공공데이터_인증키_발급안내_20260902.md`)에 "성격: 보조 경로. 키가 없어도 온비드 공개 원문 분석은 그대로 동작합니다"라고 적혀 있을 뿐, 요금에 관한 언급은 없다. **[관측: 문서에 요금 언급 없음]**
- 공공데이터포털 Open API는 일반적으로 활용신청(인증키 발급) 후 **무료**로 쓰고, 일일 트래픽 건수만 제한하는 정책으로 알려져 있다. 다만 이번 조사에서 공식 요금 페이지(`data.go.kr`)는 로그인 페이지로만 리다이렉트돼 요금 조항 원문을 직접 열람하지 못했다. **[추론 — 업계 통념, 1차 소스 미확인]**
- 결론: 공공데이터 API·온비드 크롤링 쪽의 건당 변동비는 **0원으로 추정**한다. 이 추정이 틀렸다면(트래픽 초과 시 과금 등) 이번 조사가 놓친 부분이다.

## 4. 실제로 쓰는 모델 확인과 은퇴 리스크 [관측 + 인용]

- 코드 기본값은 `gemini-2.5-flash-lite`다(`server.py:977`, `1609`, `1915`, 환경변수 `VERTEX_GEMINI_MODEL`/`GEMINI_MODEL`로 덮어쓸 수 있으나 기본값 사용).
- 상주 서버의 launchd 설정(`~/Library/LaunchAgents/com.dale.hometest-server.plist`)에는 `GOOGLE_CLOUD_PROJECT`만 지정돼 있고 모델명 환경변수는 없다. `.env.local`에도 모델명 지정이 없다. → **운영 서버도 기본값 `gemini-2.5-flash-lite`를 그대로 쓰고 있다.** **[관측]**
- 09-21 문서가 우려했던 리스크가 현실이 됐다. CloudZero 기사(최종 업데이트 2026-09-30)는 "Gemini 2.5 Flash-Lite at $0.10/$0.40 until its **October 16** retirement"라고 명시한다. 같은 기사에 "the 2.5 family retires mid-October"라는 서술도 있다. **오늘(2026-10-16)이 바로 그 날짜다.** **[인용: CloudZero, 2026-09-30 최종 업데이트]**
- 공식 Gemini Developer API 가격 페이지(`ai.google.dev/gemini-api/docs/pricing`, 2026-10-16 직접 열람)에는 **이미 `gemini-2.5-flash-lite`가 목록에서 빠져 있다.** 지금 나열된 모델은 Gemini 4 Argon·Gemini 3.8/3.7/3.6 Flash·Gemini 3.x Live 계열뿐이다. **[관측]**
- 그런데 같은 날(2026-10-16) 실제로 Vertex AI `generateContent`를 `gemini-2.5-flash-lite`로 직접 호출해보니 **정상 응답(토큰 사용량 포함)이 돌아왔다**(§5). **[관측]**
- 🔴 세 사실을 합치면: 공식 가격 페이지에서는 빠졌지만 API 자체는 아직 요청을 받아주고 있다. "은퇴"가 정확히 몇 시에 어떤 범위로 적용되는지(완전 차단인지, 기존 사용자에게는 유예가 있는지)는 **확인하지 못했다.** 이 모델이 **오늘 중 또는 가까운 시일 내에 완전히 끊길 가능성**이 있다는 뜻이다. **[추론 — 이번 조사 범위 밖, 모델 교체 필요 여부를 별도로 확인할 것을 권한다]**

## 5. 실측 — 실제 샘플 공고로 리포트 생성 실행 [관측]

- 샘플 URL: 03번 문서에 기록된 시연용 실 URL 1건(부산 금정구 서동 교육연구시설, 매각, 입찰기간이 2027-05까지라 아직 유효).
- `Hometest_op-agentic/src/server.py`를 `python3 -I`로 직접 import해 `build_notice(url)`을 실제로 호출했다(네트워크 호출 포함). 결과: `aiCoach.llmStatus == "connected"`, `aiCoach.model == "gemini-2.5-flash-lite"`. `vertex_access_token()`이 성공해 **Vertex AI 경로로 연결**됐다(이 기기에 gcloud ADC 인증이 연결돼 있다 — known-pitfalls에 이미 기재된 상태).

## 7. 4,900원 가격과 비교

- 4,900원 ÷ 약 0.30원 ≈ **약 16,000배**.
- 09-21 문서가 `/api/ask` 기능에서 내린 결론("원가는 가격을 제약하는 요인이 아니다")과 같은 패턴이다. 리포트 생성 쪽도 LLM API 원가가 가격 결정에 실질적 제약을 주지 않는다.
- v04 슬라이드가 인용한 "원가 700~1,000원"(등기부등본 발급 비용)은 이 리포트의 LLM API 원가와는 전혀 다른 항목이다. 두 수치를 같은 자리에서 "원가"로 섞어 쓰면 안 된다 — 등기부등본 비용은 사용자가 리포트를 보고 직접 등기부등본을 발급받을 때 드는 **사용자 측 비용**이고, 이번 문서가 잰 것은 **OPADA 운영사가 리포트 1건을 만드는 데 쓰는 LLM API 비용**이다.

## 8. 모델 교체 후 [관측]

- §4가 남긴 미검증("언제 완전히 끊기는지")을 그대로 둔 채, 2026-10-16 중 `gemini-3.1-flash-lite`로 선제 교체했다. 교체 시각 기준으로 `gemini-2.5-flash-lite`는 Vertex AI `generateContent` 직접 호출에서 여전히 HTTP 200 정상 응답을 반환했다 — 즉 교체 당시에는 아직 끊기지 않은 상태였고, 발표(2026-10-22)까지 끊길 위험을 선제로 없애는 목적의 교체다. **[관측]**
- 대체 모델 선정: 공식 가격 페이지(`ai.google.dev/gemini-api/docs/pricing`, 2026-10-16 브라우저로 재열람)에서 `gemini-2.5-flash-lite`가 여전히 빠져 있고, 현재 목록에는 Gemini 4 Argon·3.8 Flash·3.6 Flash·Live 계열·3.5 Flash-Lite·3.1 Flash-Lite가 있다. **[관측]**
  - 🔴 WebFetch(요약 모델 경유)는 처음에 "gemini-2.5-flash-lite가 목록에 포함돼 있다"고 잘못 답했다. 브라우저로 직접 페이지를 열어 재확인한 결과 그 모델은 없었다 — §4의 관측과 일치한다. WebFetch 같은 요약 경유 도구의 결과는 그대로 믿지 않고 직접 열람으로 재확인해야 한다는 사례다. **[관측]**

- 🔴 **운영 반영 여부는 별도 확인이 필요하다 [관측]**: 운영 중인 launchd 서비스(`com.dale.hometest-server`)는 `Hometest_op-agentic/src/server.py`가 아니라 **`Hometest_op/src/server.py`(이 레포 안의 별도 사본)를 실행한다.** 두 파일을 비교(`diff`)한 결과 `Hometest_op/src/server.py`는 `/api/ask` 속도 제한·질문 분류 `general` 갈래 추가 같은 agentic 레포의 최근 커밋이 반영되지 않은 **구버전**이었다. 즉 agentic 레포의 모델명만 바꾸는 것으로는 운영 서버에 아무 영향이 없다. 운영 반영 방법(모델명만 운영 사본에도 똑같이 바꿀지, agentic의 최신 server.py 전체를 배포할지)은 사용자 확인 후 결정하기로 하고, 이 문서 작성 시점에는 **아직 운영 서버에 반영되지 않았다.**
