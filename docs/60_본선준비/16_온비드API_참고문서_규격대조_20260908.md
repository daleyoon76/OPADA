### 2.1 `pbancMngNo` — 규격 확인 완료 (기존 「미확인」 해소)

- 규격 샘플 `202406-21411-00` → `YYYYMM-NNNNN-NN` (6-5-2, 하이픈 2개).
  - 출처: `15157218_…공고상세_조회서비스.docx` · `15157256_…공고상세_입찰정보_조회서비스.docx`
- 우리가 페이지에서 뽑는 값은 `202608-28020-01` 이다(`14_캠코_API형식_신고메일_초안_20260907.md:70`). **자릿수·하이픈 위치가 규격과 같다.** `[인용]`
- 코드는 이 값에 아무 변환도 하지 않고 그대로 넘긴다(`src/server.py:920·936·937`). **변환할 필요가 없는 것이 맞다.**

### 2.2 `pbctCdtnNo` — 규격 확인 완료 (기존 「미확인」 해소)

- 규격은 **NUMBER(22)**, 샘플 `3621804`. **하이픈이 없다.** `cltrMngNo` 와 같은 규칙으로 다루면 안 된다.
  - 출처: `15157247_…부동산_물건상세_조회서비스.docx` 요청 메시지 명세
- 우리가 URL 에서 뽑은 실측값은 `5988361` · `6151037` · `6178800` · `5803870` · `5988631` — 전부 숫자 7자리, 하이픈 없음 `[관측]`.
- 코드에 하이픈을 붙이거나 떼는 지점이 없다. **일치.**

### 2.3 `cltrMngNo` — 캠코 회신과 문서가 일치

> `cltrMngNo | 물건관리번호 | VARCHAR(100) | 1 | 2024-1100-084555 | 물건관리번호(물건목록에서 제공)`
> — `15157247_한국자산관리공사_차세대_온비드_부동산_물건상세_조회서비스.docx` 요청 메시지 명세

- 같은 문서의 응답 예시도 `<cltrMngNo>2025-1200-015749</cltrMngNo>` 로 하이픈이 있다.
- 우리 `api_cltr_mng_no()` 는 숫자 14자리를 4-4-6 으로 만든다 — 규격과 같다.

## 3. 형식 불일치는 아니지만 이번 대조에서 드러난 것 3건

### 3-1. 🟡 스킴 — 규격은 `https`, 코드는 `http` (6/6)

- 참고문서의 「서비스URL · 운영환경」은 6종 전부 `https://apis.data.go.kr/B010003/…` 다.
- `src/server.py:25-30` 의 `PUBLIC_DATA_ENDPOINTS` 는 6종 전부 `http://` 다.
- **동작은 한다** — `http`/`https` 둘 다 게이트웨이에 도달해 같은 응답을 준다(더미 키로 각각 HTTP 403 · 212바이트 · `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`) `[관측 · 2026-09-08]`.
- 그래도 고칠 값이다. `http` 는 **인증키가 평문으로 나간다.**

### 3-2. 🔴 미배선 2종의 필수 파라미터가 코드에 없다

`notice_list`·`real_estate_list` 는 정의만 있고 호출부가 없다. 지금 호출부를 만들면 즉시 `resultCode 11 · NO_MANDATORY_REQUEST_PARAMETERS_ERROR` 다.

- `notice_list`(공고목록) 필수 4개 — `cltrTypeCd`(`0001`=부동산) · `prptDivCd`(재산유형, 복수는 쉼표) · `opbdDtStart`·`opbdDtEnd`(개찰일 `yyyyMMdd`)
- `real_estate_list`(부동산 물건목록) 필수 2개 — `prptDivCd` · `pvctTrgtYn`(`Y`/`N`)
- 현재 `call_public_data()` 의 `base_params` 는 `pageNo`·`numOfRows`·`resultType` 3개뿐이다.

### 3-3. 🟡 게이트웨이 오류 봉투를 `api_header()` 가 못 읽는다

- 게이트웨이 오류는 `{"OpenAPI_ServiceResponse": {"cmmMsgHeader": {"returnReasonCode": "30", …}}}` 구조다 `[관측]`.
- `api_header()`(`src/server.py:822`)는 `response.header` · `result` · `header` 세 형태만 본다. 위 구조는 `{}` 가 되어 `resultCode` 가 빈 문자열이 된다.
- 영향: 이 봉투가 **HTTP 200 으로 오는 경우**(요청제한 초과 `22` 등) 화면 판정이 `failed` 로 떨어지고 메시지가 원인을 말하지 않는다.
  - 개발계정 한도가 **일 1,000건**으로 확정된 지금(§4) 실제로 닿을 수 있는 경로다.
  - HTTP 403 으로 오는 경우는 `urllib` 이 `HTTPError` 로 잡아 「권한 반영 대기」 메시지를 내므로 화면은 깨지지 않는다.
