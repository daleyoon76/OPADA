## URL 형식 참고

- 온비드 물건상세는 POST 이동이라 주소창에 파라미터가 남지 않는다.
- GET으로 여는 데 필요한 파라미터는 **4개**다: `onbidCltrno`, `pbctCdtnNo`, `onbidPbancNo`, `pbctNo`.
- 이 중 하나라도 빠지면 온비드가 HTTP 500을 반환한다.
- ⚠️ 2026-09-02 기재의 「`cltrHisNo` 포함 5개」는 오기다. 2026-09-08 실측(파라미터를 하나씩 빼며 5회 요청)에서 `cltrHisNo` 만 빼면 HTTP 200·722,685바이트였다. 위 URL 3건은 5개를 다 담고 있으므로 그대로 유효하다.
- 🔴 **위 4개 중 `pbctCdtnNo` 는 물건상세 페이지에만 있다.** 그래서 앱이 만드는 `itemDetail` 링크가 열리는지는 **사용자가 무엇을 붙여넣었느냐**에 달렸다(2026-09-08 실측).
