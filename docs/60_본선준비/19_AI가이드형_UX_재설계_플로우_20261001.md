## 1. 방향 확인 [관측]

동원님이 확정한 방향은 옵션 B다.

- 기능·판단 로직은 바꾸지 않는다.
- 화면의 태도만 "정보 나열"에서 "AI가 순서대로 안내"로 바꾼다.
- 제출한 사업계획서의 "판단하지 않는다" 약속과 캠코 멘토링 M4("밸리데이션으로 만들면 안 된다")는 그대로 지킨다.

이 문서는 구현 전 검토용 플로우 다이어그램이다. 코드는 아직 건드리지 않았다.

## 2. 전체 화면 흐름 (변화 없음)

화면 3개(공고 가져오기 → 준비 보드 → 관심 공고) 구조 자체는 바뀌지 않는다. 바뀌는 자리는 준비 보드 **안**의 안내 방식이다.

```mermaid
flowchart TD
    A["#input 공고 가져오기<br/>온비드 URL 입력"] --> B["분석 실행<br/>server.py 공공데이터·원문 파싱"]
    B --> C["#report 준비 보드<br/>(3절에서 재설계)"]
    C --> D["#watchlist 관심 공고<br/>자동 저장·목록"]
    C -. "언제든 다시 분석" .-> A
```

## 3. 준비 보드 내부 안내 흐름 (신규)

지금은 AI 코치 패널·다음 액션·서류 체크리스트·접힌 패널 6개가 **병렬로 나열**되어 있고, 질문-답변 위젯은 코치 패널 안에 묻혀 있다. 사용자가 전부 훑어야 한다.

바꾸는 방향은 AI 코치가 **먼저 말을 걸고 순서를 짚어 주는** 흐름이다.

```mermaid
flowchart TD
    Start["준비 보드 진입"] --> Hero["공고 요약 배지<br/>(기존 그대로)"]
    Hero --> Coach["AI 코치 패널<br/>1인칭 안내 톤으로 교체<br/>'이 공고는 OO이니 먼저 OO부터 확인하시죠'"]
    Coach --> Priority{"AI가 짚은<br/>우선순위 항목 있음?"}
    Priority -- "있음" --> Highlight["다음 액션 목록에서<br/>해당 항목을 강조 표시<br/>(기존 aiMatch 로직 재사용)"]
    Priority -- "없음" --> TaskList["다음 액션 목록<br/>(기존 그대로, 강조 없음)"]
    Highlight --> TaskList
    TaskList --> Ask["질문-답변 위젯을<br/>상시 노출 카드로 승격<br/>'궁금하면 언제든 물어보세요'"]
    Coach -. "관련 세부정보 딥링크" .-> Panels["접힌 패널 6종<br/>(마감·비용 요약 / 확인 질문 모음 등)<br/>AI 코치가 '여기서 확인하세요'로 연결"]
    Ask -. "답변 중 참고 자료 언급 시" .-> Panels
```

## 4. 기존 대비 변경 요약

- AI 코치 패널 문구: 명사형 나열 → 1인칭 안내 톤. **문구만 교체**, 판단 로직 변경 없음.
- 다음 액션 목록: 이미 있는 `aiMatch`(AI 우선순위 매칭) 로직을 시각적으로만 더 강조. 새 판단 로직 추가 없음.
- 질문-답변 위젯: 코치 패널 하단에서 독립 카드로 승격. 기존 `/api/ask` 호출 그대로 재사용.
- 접힌 패널 6종: 코드·구조는 그대로 두고, 코치 패널이 관련 패널로 안내 링크만 추가.

전부 **표시 순서·강조·문구** 변경이고, 추출·분석·체크리스트 판정 로직은 손대지 않는다.
