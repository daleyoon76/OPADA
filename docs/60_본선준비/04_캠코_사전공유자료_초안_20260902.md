## 5. 확인 요청 사항

회신에서 수락해 주신 "데이터 항목 해석의 정확성 확인"에 해당하는 부분입니다. 화면에 쓰는 용어와 설명 문구가 온비드 실제 기준과 어긋나지 않는지 짚어 주시면 됩니다.

화면에 표시하는 항목은 다음과 같습니다.

- 분석 미리보기: 공고/물건명, 유형(재산유형 / 처분방식), 입찰기간, 가격/보증금
- 공고 요약: 공고번호, 공고기관, 입찰방식, 가격/보증금
- 준비 보드: 일정 알림, 비용 항목, 제출서류, 담당기관 확인 질문

특히 아래 세 가지를 여쭙고자 합니다.

1. **재산유형과 처분방식의 표기** — 화면에는 "기타일반재산 / 임대"처럼 온비드 값을 그대로 씁니다. 일반 이용자에게 이 표기가 통하는지, 풀어 써야 하는 용어가 있는지 확인 부탁드립니다.
2. **가격 항목의 명칭** — 화면에서는 "가격/보증금"으로 묶어 표시합니다. 매각과 임대에서 이 항목이 가리키는 값이 다른데, 구분해서 불러야 할 명칭이 있는지 확인 부탁드립니다.
3. **최저입찰가격이 제공되지 않는 경우** — 회차 선택형 공고는 원문에 단일 최저입찰가격이 없습니다. 이때 화면에 어떻게 표시하는 것이 적절한지 의견을 구하고자 합니다.
