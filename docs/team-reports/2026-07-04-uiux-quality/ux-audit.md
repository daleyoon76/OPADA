# UI/UX 품질 진단

작성일: 2026-07-04

## 진단 요약

사용자 피드백 기준으로 기존 `준비 보드`는 실제 작업판이 아니라 정보 카드 묶음처럼 보였다. 정보와 액션의 구분이 약했고, 오늘 할 일·마감·비용·관심 공고 상태가 같은 강도의 카드로 펼쳐져 사용자가 다음 행동을 파악하기 어려웠다.

## P0

| 문제 | 조치 |
| --- | --- |
| 체크 가능한 task 흐름 부재 | 다음 액션 영역을 체크박스 기반 작업 리스트로 변경 |
| 시스템 자동 판정과 사용자 완료 상태 혼재 | `공고 유형 확인`은 자동 분석 카드로 분리하고, 진행률은 사용자 체크 항목만 계산 |
| 설명 텍스트 과다 노출 | 근거/세부 조건은 `details`로 접힘 처리 |
| 마감·비용·관심 공고 정보 과다 노출 | 보조 섹션은 기본 접힘 처리 |

## P1

| 문제 | 조치 |
| --- | --- |
| 체크박스가 핵심 조작으로 약하게 보임 | 체크박스 크기 확대, task row hover, row 전체 클릭 affordance 강화 |
| 우측 CTA와 상단 탭 명칭 혼선 | `서류 준비처 보기`, `문의 질문 확인`, `준비 리포트 저장`으로 동사형 변경 |
| 사용자 유형 변경 시 task 불일치 | 개인/개인사업자/법인/예비창업자별 task 필터 적용 |
| 진행률 접근성 부족 | `role="progressbar"`와 `aria-valuenow/min/max`, `aria-live` 적용 |
| 분석 중 중복 클릭 가능 | 분석 중 버튼 disabled 처리 및 완료 후 준비 보드 제목 focus 이동 |

## 현재 판정

- P0 없음.
- P1은 제출용 스크린샷 기준 수용 가능한 수준으로 반영됨.
- 남은 개선 후보는 실제 사용자 테스트에서 task 문구와 준비처 링크 유용성을 검증하는 것이다.

## 18:04 추가 점검

사용자가 `공고 분석` 후 바로 준비 보드로 넘어가는 흐름과 관심 공고 가치 부족을 지적해 추가 UI/UX 점검을 수행했다.

### P0

없음. 분석, 준비 전환, 체크리스트, 관심 공고 흐름에서 막히는 상태는 확인되지 않았다.

### P1 반영

| 문제 | 조치 |
| --- | --- |
| 분석 결과를 확인하기 전에 준비 보드로 이동함 | 분석 미리보기 화면을 추가하고 `준비 보드 만들기`를 별도 CTA로 분리 |
| 분석 완료 후 `공고 분석`과 `준비하기`가 둘 다 primary처럼 보임 | `다시 분석`은 secondary, `준비 보드 만들기`는 primary로 계층 정리 |
| 입력 라벨이 공고번호 단독 입력까지 지원하는 것처럼 보임 | `온비드 공고/물건 URL`로 실제 지원 범위에 맞춤 |
| AI 코치 본문이 길고 판단 유도 표현 가능성이 있음 | 3개 행동/2개 질문 중심으로 줄이고 안전 후처리 추가 |
| `검토 메모 복사`가 준비 보드 핵심 CTA보다 강해 보임 | secondary 버튼으로 낮춤 |
| 관심 공고가 정적 샘플처럼 보임 | `최근 살펴본 공고`와 별표 기반 관심 추가 흐름 구현 |

### 현재 판정

- 신청서 캡처 기준 메인 추천 화면은 `validation/15_url-preview-prepare-vertex-ai.png`.
- `validation/16_input-analysis-preview-vertex-ai.png`는 실제 URL 분석/AI 코치 연결 증거로 적합하다.
- `validation/17_watchlist-recent-favorite.png`는 반복 사용 가치와 여러 물건 관리 확장성을 보여주는 보조 증거로 적합하다.
