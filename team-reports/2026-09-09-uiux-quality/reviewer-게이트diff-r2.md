## 7. 최종 커밋에서 확인할 종료 조건 1개

P1-1·P1-2 를 반영한 뒤 실행한다. **요약 줄 · 🔴 축 대조 · 모수 · 종료코드 뒤집기를 한 번에 본다.**

```bash
cd /Users/user/Documents/Dev/Hometest_op && \
npx playwright test tests/screen.spec.js >/tmp/g-full.log 2>&1; FULL=$?; \
npx playwright test tests/screen.spec.js --grep-invert "커버리지 측정" >/tmp/g-cut.log 2>&1; CUT=$?; \
grep -qE '^11/16 통과' /tmp/g-full.log \
  && grep -q 'P0-5' /tmp/g-full.log && grep -q 'P0-6' /tmp/g-full.log \
  && grep -qE '실제로 붉은 축 5개: N1, N2, N3, N5, N6' /tmp/g-full.log \
  && grep -qE '🔴 모수' /tmp/g-cut.log && [ "$CUT" = 1 ] \
  && ! grep -qE '🔴' <(grep -v '모수\|붉음(의도)\|선언에 없는데\|도달 단정\|음성 대조\|건너뛴\|붉히면 안 되는' /tmp/g-full.log) \
  && echo "GATE-OK ($FULL/$CUT)" || echo "GATE-FAIL ($FULL/$CUT)"
```

- 조건의 뜻
  1. `11/16 통과` — 붉은 축 5개를 초록으로 «만들지 않았다».
  2. `P0-5`·`P0-6` 이 이름으로 찍힌다 — 축 없는 P0 이 숨지 않는다.
  3. `실제로 붉은 축 5개: N1, N2, N3, N5, N6` — **요약 줄이 상쇄로 안 움직여도** 축 귀속이 맞는지 본다(J1 변이 교훈).
  4. **커버리지 측정 테스트 하나만 빼면 🔴 모수 경고가 뜨고 종료코드가 1이다** — P1-2 가 닫혔다는 증거이자 킬러 변이다.
- ⚠️ `11/16` 은 이 워킹트리 시점 값이다. test 를 더하거나 빼면 이 숫자와 `EXPECTED_TEST_COUNT` 를 **같은 커밋에서** 갱신한다.
- ⚠️ 요약 줄이 없으면 그 실행은 크래시이고 뒤 축은 돌지도 않은 것이다 — `GATE-FAIL` 로 떨어진다.
