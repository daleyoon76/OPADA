## 7. 최종본에서 확인할 종료 조건 1개

```bash
cd /Users/user/Documents/Dev/Hometest_op
R='team-reports/2026-09-09-uiux-quality/00-종합-재기획안.md'
[ -s "$R" ] || { echo "FATAL: 대상 없음/빈 파일"; exit 2; }   # 모수 하한
fail=0
chk(){ eval "$2" && { echo "MISS: $1"; fail=1; } || echo "ok: $1"; }

# P0-D — 표본 크기를 화면 문안에서 말하지 않는다
chk "P0-D 표본 일반화 문안 잔존"      'grep -q "표본에서는 목록이 없었습니다" "$R"'
chk "P0-D 첨부 내보내기 금지 과교정"   'grep -q "첨부를 확인하라고 내보내기" "$R"'
# P0-E — 미측정 빈도 단언
chk "P0-E 보통-공고문 빈도 주장 잔존"  'grep -q "보통 공고문 파일에 있습니다" "$R"'
# P0-F — 화면 문자열 게이트 신설 (있어야 하므로 부정 조건)
chk "P0-F 화면 문자열 게이트 미기재"   '! grep -q "화면 문자열.*금지표현\|표시 문자열.*12종" "$R"'
# P1-6 — 절 제목 정정
chk "P1-6 절 제목 2클릭에서 1클릭 잔존" 'grep -q "4-2\. 사용자 여정 — 2클릭에서 1클릭" "$R"'
# P1-7 — C형 문안 두 판본
chk "P1-7 C형 문안 판본 2개"           'grep -q "담당기관에 물어볼 문장을 준비" "$R" && grep -q "담당기관 확인 문장을 준비" "$R"'
# P1-10 — 파서 결정 충돌
chk "P1-10 파서 도입 결정 미결 잔존"   'grep -q "파서 도입 결정을 받는다" "$R"'

echo "checks_failed=$fail"; exit $fail
```

- **통과 기준: 모든 축이 `ok:` 이고 `checks_failed=0`, `exit 0`.**
- 모수 하한: `$R` 이 없거나 비면 `exit 2` 로 끊는다 — 입력이 비어 기본 분기에서 초록이 나는 경로를 막는다.
- 이 조건이 닫는 것: **문서 승계·문안 일관성뿐이다.** P0-E·P0-F 의 실질(적중률 측정 · 코드 게이트 실행)은 닫지 않는다. 그것은 2팀 packet 과 `src/` 게이트의 영역이며, 여기서는 「문서가 그 항목을 갖고 있는가」만 센다.
