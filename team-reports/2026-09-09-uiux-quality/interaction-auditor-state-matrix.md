# 2. P0 — 거짓 안내

### P0-1. 부분 추출을 「추출됨(초록)」으로 말한다
- 증상: 닫힌 어휘 36종 밖 서류가 있어도, 본문 목록이 불완전해도 화면은 `추출됨`(safe) + `공고 원문에서 서류 N건을 찾았습니다`.
- 근거: `server.py:517-519` 는 `items` 가 1건이라도 있으면 `extracted` `[관측]` · `notes` 4종에 「닫힌 목록」 경고 없음 `server.py:530-539` `[관측]` · 첨부 병행확인 note는 profile B 전용 `server.py:537` `[관측]` · A형 국유재산 5건은 「미성년자」 조건이 본문에 없음 `07_제출서류_표본조사:77` `[인용]`.
- 손해: 표본 A형 8건 중 5건에서 사용자가 화면 목록을 완전한 것으로 믿고 첨부를 열지 않는다. 빠진 서류는 입찰 당일에 발견된다. known-pitfalls 의 「목록에 없는 서류는 못 뽑음으로 보고돼야 한다」가 **items=0 일 때만** 지켜지고 부분 케이스에서 깨져 있다.

### P0-2. 첨부를 열지 않고 「원문에 없음」이라고 단정한다
- 증상: 파산자산 공고에서 배지 `원문에 없음`, 그 아래에 첨부파일 목록이 그대로 렌더된다.
- 근거: `server.py:520-522` 가 `attachments` 검사보다 먼저 `profile.code=="C"` 를 본다 `[관측]` · 첨부 내부 미개봉 `server.py:590` `[관측]` · 배지 문구 `app.js:950` · 첨부 렌더 `app.js:1041-1050`.
- 손해: 첨부에 목록이 있는 파산 공고에서 사용자가 첨부를 열지 않는다. 판정 근거가 「이 공고 관측」이 아니라 「표본 2건 기반 재산유형 추론」인데 화면은 관측처럼 말한다.

### P0-3. 대다수 입력에서 500 인 링크를 정상 링크로 제시한다
- 증상: `물건상세` 링크가 `공고보기` 와 동일한 스타일·동일한 확신으로 나온다.
- 근거: `app.js:867` 은 `links.itemDetail` 의 존재만 본다 `[관측]` · `server.py:1061` 은 `onbidCltrno` 만 보고 `pbctCdtnNo` 유무를 보지 않는다 `[관측]` · 공고상세 입력 시 HTTP 500, 표본 `pbctCdtnNo` 보유 0/23 `known-pitfalls.md:62-65` `[인용]`.
- 손해: 표본 분포대로면 공고상세를 붙여넣는 사용자 전원이 죽은 링크를 받는다. 시연에서 이 링크를 누르면 온비드 에러 화면이 뜬다.

### P0-4. 값이 「지금 것」처럼 보인다 (M14)
- 증상: 기준 시각·데이터 출처 표기가 화면 어디에도 없다. `마감 D-2` 같은 단정 배지만 있다.
- 근거: `src/` 전수 grep — `30분|지연|freshness|기준 시각|갱신|최신` **0건** `[관측]` · 가격은 원문 hidden input 또는 API 값 중 하나인데 구분 표기 없음 `server.py:1730-1734` `[관측]`.
- 손해: 최대 30분 지연된 보조 데이터 값을 실시간으로 오인한다. 마감 임박 공고에서 손해가 비가역이다.

### P0-5. 저장하지 않은 관심 공고를 「N건」으로 센다
- 증상: 실제 분석 후에도 `관심 공고 2건` 이 표시된다. 사용자는 아무것도 저장하지 않았다.
- 근거: 서버가 모든 응답에 placeholder 2건을 실어 보낸다 `server.py:1870-1883` `[관측]` · `savedItems` 가 이를 항상 합산 `app.js:1352-1365` `[관측]` · 행마다 `예시` 배지는 붙지만 **요약 숫자는 구분하지 않는다** `app.js:1368-1370` `[관측]`.
- 손해: 개수 자체가 거짓. 2026-08-08 리포트의 「관심 공고 빈 상태 도달 불가」 P1 이 **미해소**임이 확인된다.

### P0-6. LLM 을 호출하지 않았는데 「AI 분석 완료」라고 말한다
- 증상: API 키 없는 기본 구성에서도 `AI 분석 완료`, `AI가 미해결 항목만 골랐습니다` 가 그대로 표시된다.
- 근거: `build_ai_coach` 폴백이 `llmStatus="rule_based"` 를 넣는다 `server.py:1543` `[관측]` · 화면은 텍스트를 바꾸지 않고 **배지 색만** safe→warn 으로 바꾼다 `app.js:896-897,919-920` `[관측]`.
- 손해: 사실이 아닌 것을 말하며, 동시에 색으로만 정보를 전달해 접근성 기준(WCAG 1.4.1)도 깬다. 발표 시연에서 「AI 라고 썼는데 규칙 엔진」이 지적당하면 금지표현 가드레일 논쟁으로 번진다.
