### P1-3 — 화면에 오르는 문장 중 **아직 확정되지 않은 것**이 구현으로 넘어간다

판정 질문 3에 대한 답: **§4-3에 명시된 화면 문안 3종에는 「낙찰 가능성」·「수익성」·「추천」류가 없다. 그 범위에서는 제외 범위를 지킨다** `[관측 · 118-120줄 대조]`. 다만 아래가 열려 있다.

- **「AI 누락 점검」 라벨의 to-be 문안이 없다.** §5 4번은 「`llmStatus` 에 따라 텍스트 분기」라고만 하고 **분기 후 문자열을 제시하지 않는다** `[관측 · 149줄]`. `CLAUDE.md:23` 금지표현 12종에 **「Vertex AI/Gemini AI」**가 있고, 이 화면은 캠코 시연에 그대로 나간다. 「AI」 라벨을 어떻게 쓸지 문서가 정하지 않은 채 구현자에게 넘어간다.
- **금지표현 가드가 LLM 경로에만 걸린다.** §7-1의 4단계는 `sanitize_ai_text` 를 대상으로 한다. 그러나 캠코 시연에서 더 많이 뜨는 것은 `headline`·`notes`·`profile.label` 같은 **결정적 문자열**이고, 이들은 관문 밖이다 `[관측 · server.py:518-539 는 sanitize 를 거치지 않음]`. `CLAUDE.md:63` 은 「화면 상태 문구·금지표현 목록은 외부 SSOT」라고 못 박는데, **전체 화면 문자열 ↔ 금지표현 12종 대조** 축이 재기획안에 없다.
- **진행률 대책이 색뿐이다.** 122줄은 「채움색을 중립으로」만 적는다. 100% 도달 시 문안이 무엇인지 없다 (P2로 내려도 무방).
- **고치는 법** — §7-1 가드의 적용 대상을 `sanitize_ai_text` 1곳이 아니라 **「화면으로 나가는 모든 문자열 상수」**로 넓히고, 게이트 1개를 「`server.py`·`app.js`의 사용자 표시 문자열을 금지표현 12종과 대조」로 신설한다. 「AI 누락 점검」의 대체 문안 후보 2개를 문서에서 확정한다.

### P1-4 — 표본 비율을 모집단 비율처럼 쓴다. 「층화추출 아님」이 원장에만 있다

### P1-5 — 「notes 4종 어디에도 없다」가 과대 진술이다

- P0-1(78줄)은 「닫힌 어휘 36종 밖은 못 뽑는다는 경고가 `notes` 4종 어디에도 없다」고 적는다.

## 6. 권고를 반영한 뒤 최종본에서 확인할 종료 조건 1개

**기계적으로 실행 가능한 형태:**

```bash
cd /Users/user/Documents/Dev/Hometest_op
R='team-reports/2026-09-09-uiux-quality/00-종합-재기획안.md'
fail=0
# ⑴ known-pitfalls 3대 실측이 재기획안 본문에 승계됐는가 (P0-B · P1-2)
for k in 입찰방법 DOC_SEARCH_SECTIONS generic 구분명; do
  n=$(grep -c "$k" "$R"); [ "$n" -ge 1 ] || { echo "MISS: $k=0"; fail=1; }
done
# ⑵ B형 여정이 A형과 갈려 적혔는가 (P0-C)
grep -q '파서 전' "$R" || { echo "MISS: B형 파서 전/후 행 분리"; fail=1; }
# ⑶ C형 처방이 attachment_only 로 넘기지 않는가 (P0-A)
grep -n 'profile=="C"' "$R" | grep -q 'attachments' && { echo "MISS: C형 순서뒤집기 잔존"; fail=1; }
# ⑷ 최우선 기여 열이 있는가 (P1-1)
grep -q '최우선 기여' "$R" || { echo "MISS: 최우선 기여 열"; fail=1; }
# ⑸ 층화추출 한계가 원장 밖 본문에도 있는가 (P1-4)
[ "$(grep -c 층화 "$R")" -ge 2 ] || { echo "MISS: 층화 한계 본문 미기재"; fail=1; }
echo "checks_failed=$fail"; exit $fail
```

- **통과 기준: `checks_failed=0` 이고 `exit 0`.**
- 모수 하한: 위 5개 검사는 전부 `$R` 이 존재하고 비어 있지 않을 때만 의미가 있다. `[ -s "$R" ]` 이 거짓이면 이 스크립트는 통과로 세지 않는다.
- 이 조건은 **문서 승계 여부만** 닫는다. P0-B의 「첨부 텍스트에서 「입찰방법」 도움말이 실제로 오탐되는가」는 코드 게이트 영역이며, 2팀 packet의 고정 행으로 넘긴다.

현행 `00-종합-재기획안.md`(sha256 `b9dd3e5a…`)에 위 스크립트를 그대로 태운 결과 `[관측 · 2026-09-09 KST]`:
