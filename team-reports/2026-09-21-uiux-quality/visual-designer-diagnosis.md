# visual-designer 진단 — 관심 공고 탭 (2026-09-21)

대상: `#view-watchlist` 카드형 리스트. 전체 디자인 테마(팔레트·폰트·톤앤매너)는 범위 밖 — 기존 색상·폰트를 그대로 쓰면서 간격·밀도·계층·정렬·대비만 본다.

## P0 (레이아웃 깨짐)

- **모바일 소제목 어색한 줄바꿈.** 375~390px에서 "관심 공\n고", "최근 살펴\n본 공고"로 실제 줄바꿈됨. 원인: `styles.css:1052` `.watch-section-title{display:flex; justify-content:space-between}`가 h3(짧은 라벨)와 p(긴 설명문)를 한 행에 두는데 `flex-shrink` 제어가 없고, 이 클래스가 900px 모바일 브레이크포인트 예외 목록에서 빠져 있다.
- **"예시" 배지가 폭 넓은 바(bar)로 렌더.** 샘플 카드 제목 아래 "예시" 텍스트가 작은 pill이 아니라 카드 폭 대부분을 채우는 옅은 주황 바로 나타남. 원인: `styles.css:1071` `.watch-item span:not(.star-placeholder){display:block}`의 명시도(class 2 + type 1)가 `.badge{display:inline-flex}`(class 1)보다 높아 badge span의 display·color를 강제로 덮어씀. 의도된 디자인이 아니라 선택자 과잉범위 버그.

## P1 (위계·대비 약함)

- **별표/배지 대비 부족.** 채워진 상태 색상(`--amber #f5901e` on `--soft-amber #fde8d0`)의 대비비 약 2.0:1로 WCAG UI 컴포넌트 최소 기준(3:1) 미달. 빈 별(`--muted` on 흰 배경)은 약 5.8:1로 양호. `.badge.warn`을 쓰는 배지 전반에 파급.
- **카드 내부 텍스트 위계 평면적.** 제목(14px 상속)과 메타(12px muted)의 차이가 2px뿐이고, 실행 중요도가 가장 높은 "다음 액션"도 동일하게 12px muted라 우선순위가 안 보임.

## P2

- 모바일에서 `.watch-item`이 1열이 되어 별 아이콘과 제목의 시각적 연결이 약해질 가능성(스크린샷 재확인 필요).
- `.watch-section-title`의 "라벨+긴 설명문 한 행" 구조는 데스크톱에서도 컨테이너 폭이 좁아지면 재발 소지.

## 반영 여부 (2026-09-21 구현·리뷰 후 갱신)

- 모바일 소제목 줄바꿈: 구현함 (`h3 { flex-shrink: 0 }`)
- "예시" 배지 렌더링 버그: 구현함 (`:not(.badge)` 선택자 추가로 배지를 규칙 범위 밖으로 뺌)
- 별표/배지 대비 부족(WCAG): 미구현 — 전역 `--amber` 변경은 테마 변경 범위라 판단해 다음 과제로 남김(visual-reviewer 재확인 요청)
- 카드 내부 텍스트 위계: 미구현 — 이번 범위 밖, 다음 과제
