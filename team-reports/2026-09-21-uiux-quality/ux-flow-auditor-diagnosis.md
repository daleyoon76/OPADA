# ux-flow-auditor 진단 — 관심 공고 탭 (2026-09-21)

대상: `#view-watchlist`, `src/app.js`의 `renderWatchlist()`(1534행)·`watchItemHtml()`(1596행), `src/index.html:155-166`. 전체 디자인 테마(팔레트·폰트·톤앤매너)는 범위 밖.

## 핵심 플로우

사용자는 "공고 가져오기 → 준비 보드 → 관심 공고" 순으로 이동하며, 관심 공고 탭에서는 ① 요약 카운터로 현재 상태를 확인하고 ② "관심 공고" 목록에서 별표한 항목을 재확인하고 ③ "최근 살펴본 공고"에서 지금까지 분석한 것들을 이어서 본다.

## P0

- **요약 숫자와 카드 개수가 직접 모순된다.** 근거: 수정 전 스크린샷 — "관심 공고 0건" 바로 아래 같은 이름의 섹션 제목에 카드 3개가 그대로 보인다(`app.js:1560` `savedByUser`는 sample 제외, `1570` `savedHtml`은 sample 포함). 첫 방문 사용자는 "0건"과 눈앞의 카드 3장 중 무엇을 믿을지 판단할 근거가 없다.
- **마감 경과 경고가 일반 진행 메모와 같은 자리·같은 무게로 나온다.** 근거: 최근 살펴본 공고 섹션의 "부산 금정구 서동 교육연구시설" 카드 — `<p>${item.next}</p>`가 "입찰 마감 지남 / 2026-09-01 17:00 마감"을 중립 문구와 동일한 폰트·색·위치로 출력한다.
- **"원문" 링크가 sample 항목 2개(매각 공고 후보·창업 공간 후보)에서 실제 공고가 아닌 onbid 홈페이지로 이동한다.** 근거: `app.js:391-396`(sourceUrl 없음) + `1551` fallback. 두 카드는 제목부터 "…후보"로 실재 공고가 아님을 암시하지만, 시각적으로는 실제 카드와 동일하고 "원문" 버튼도 똑같이 클릭 가능해 보인다.

## P1

- 같은 라벨 "관심 공고"가 탭·h2·h3 세 계층에서 반복돼 첫인상에서 탭 전체와 하위 목록의 구분이 안 된다.
- 별표 아이콘이 두 가지 다른 의미(활성/placeholder)에 같은 색·모양을 쓴다.
- 즐겨찾기한 항목이 "관심 공고"와 "최근 살펴본 공고" 두 섹션에 중복 노출된다.
- "예시" 표기가 배지 크기를 넘어 카드 폭 전체를 채우는 막대로 렌더된다(선택자 충돌 — visual-designer 진단에서 원인 확인).

## P2

- 카드 안 제목·부제·유형·다음 액션·상태·원문·별표 7개 요소가 라벨 없이 나열돼 각 값의 의미를 추론해야 한다.
